What it catches

Every blocker the reviewers actually flag.

The knowledge base is compiled from Apple's App Store Review Guidelines, Google's Play Developer Policy, and a corpus of real rejection emails. Updated against the published rules as of May 2026.

  • Apple 5.1 · Privacy

    Privacy manifest gaps

    The #1 source of ITMS-91053 emails. Detects missing PrivacyInfo.xcprivacy, undeclared Required Reason API usage, ATT setup mismatches.

  • Apple 5.1.1 · Permissions

    Usage strings missing or too generic

    Cross-references your app.json dependencies against required NS*UsageDescription keys. Flags strings under 50 chars or lacking concrete consequence.

  • Apple 3.1 · IAP

    IAP bypass attempts

    Auto-rejection trigger. Detects Stripe / external links / web-only checkout used for digital goods where StoreKit is required.

  • Apple 5.1.1(v) · Account

    Account deletion missing

    Required since 2022. Detects sign-in flows without an in-app delete path and flags the route you need to add.

  • Apple 4.8 · Sign in with Apple

    Third-party login without SiwA

    Flags Firebase Auth, Supabase, Auth0, Cognito, Clerk — including phone-OTP-only flows (per the 2024–2026 reviewer interpretation).

  • Google · Target SDK

    SDK / 64-bit / 16 KB compliance

    Detects target SDK below the current Play floor, missing 64-bit builds, and the 2026 16 KB page-size deadline.

  • Google · Permissions

    Foreground service type missing

    Every FOREGROUND_SERVICE_* permission needs a declared type in the manifest, or your release is auto-rejected.

  • Google · Data Safety

    Data Safety form misalignment

    Compares the SDKs your app ships against your declared data-collection form. Misalignment is the most common Play takedown.

  • Stability · 2.1

    Crash patterns & dev artifacts

    Localhost URLs, debug flags left enabled, force-unwraps, console warnings — anything reviewers will reproduce on first launch.

The three commands

One scan, one fast check, one fixer.

/review-ready:scan

full · ~2 min

Spawns five parallel subagents — privacy, IAP, permissions, metadata, crash-risk — and returns a severity-ranked report with exact file:line references and fixes.

  • privacy-auditor
  • iap-business-auditor
  • permissions-auditor
  • metadata-auditor
  • crash-risk-auditor

/review-ready:precheck

fast · ~30s

The top-10 blockers only. Run this right before you hit Submit for Review. If it's clean, you're clean.

  • blocker-grade issues only
  • no medium / info noise
  • 30-second feedback loop

/review-ready:fix

auto · safe edits

Auto-applies the safe fixes from the latest scan: missing usage strings, encryption export flag, PrivacyInfo.xcprivacy stub, ATT wiring for expo-tracking-transparency.

  • only touches safe deltas
  • previews every change first
  • respects existing config
