What it catches

Every blocker the reviewers actually flag.

A knowledge base compiled from Apple's App Store Review Guidelines, Google's Play Developer Policy, and a corpus of real rejection emails. Current as of May 2026.

  • Apple 5.1 · Privacy

    Privacy manifest gaps

    The #1 source of ITMS-91053 emails — missing PrivacyInfo.xcprivacy, undeclared Required Reason APIs, ATT mismatches.

  • Apple 5.1.1 · Permissions

    Usage strings missing or generic

    Cross-references your dependencies against required NS*UsageDescription keys and flags vague, under-specified strings.

  • Google §8.4 · Photos

    Photo/video permission blocker

    READ_MEDIA_IMAGES declared for one-off picking — Google's pre-review hard-blocks it. Separates one-off use from a real gallery.

  • Apple 4.8 · Sign in

    Third-party login without SiwA

    Flags Google/Facebook sign-in, Firebase, Auth0, Clerk — including phone-OTP flows — missing Sign in with Apple.

  • Apple 5.4 · Encryption

    Export compliance undeclared

    usesNonExemptEncryption unset blocks every App Store Connect upload. Auto-fixable.

  • Google · Target SDK

    Target API / FGS compliance

    Target SDK below the Play floor, and foreground services without a declared foregroundServiceType.

  • App identity

    Placeholder bundle ids

    Catches com.anonymous.* / com.example.* — which you can't change after first publish.

  • Apple 5.1.1(v)

    Account deletion missing

    Required since 2022. Detects sign-in flows with no in-app delete path.

  • Stability · 2.1

    Crash patterns & dev artifacts

    Localhost URLs, debug flags, force-unwraps — anything reviewers hit on first launch.

In the plugin

One scan, one fast check, one fixer.

/review-ready:scan

full · ~2 min

Five parallel auditors — privacy, IAP, permissions, metadata, crash-risk — return a severity-ranked report with file:line and fixes.

/review-ready:precheck

fast · ~30s

The top-10 blockers only. Run it right before Submit for Review. Clean here means clean there.

/review-ready:fix

auto · safe edits

Auto-applies safe fixes — usage strings, encryption flag, PrivacyInfo.xcprivacy stub, ATT wiring. Previews every change.

Install

Pick the plugin, or the CLI.

The plugin adds LLM judgment checks inside Claude Code, Cursor, and Codex. The CLI runs the deterministic checks with no API key — locally or in CI.

Plugin · Claude Code / Cursor / Codex

$ /plugin install review-ready

CLI · terminal & CI

$ npx review-ready-cli
